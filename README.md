# Amazon 季度交易数据核验台（上下文证据版）

一个完全运行在浏览器本地的 Amazon 季度跨境电商交易数据工具：拖入 PDF 文件夹，完成自动提取、逐字段证据核对和最终汇总确认。公司工作簿为可选项；上传时生成带公式和完整报告截图的新工作簿，不上传时直接下载解析汇总表。

在线使用：<https://sepmorning.github.io/amazon-quarterly-tool-web-context/>

此仓库是上下文证据升级版，保留字段所在区域、表头和小计后再动态标记待核验数据。原版单字段附近截图项目继续独立保留在 `amazon-quarterly-tool-web`。

## 特点

- 纯静态网页。PDF 和工作簿不会上传到服务器，也不需要安装 Microsoft Excel 或 WPS。
- 支持美国、加拿大、墨西哥、巴西、日本、德国、英国、法国、意大利、爱尔兰、瑞典、荷兰、西班牙、比利时、波兰的 Amazon Custom Summary。
- 兼容历史上把瑞典报告文件名写成 `KR` 的情况；程序会按报告实际语言与币种映射到瑞典（SE）。
- 原始 PDF 上下文证据在上：保留字段所属半区、表头与小计，并用蓝框动态标出当前数据；数值与操作在下。
- 佣金服务费同时标出 Expenses Debit subtotal 与广告费两个计算来源。
- Enter 确认并自动前进；方向键按国家与字段的线性顺序上下移动；`M`、`0`、`S` 分别处理人工值、确认零、跳过。
- “佣金服务费”按 `ABS(Expenses subtotal Debits) - 广告费` 计算并写入清晰公式，不使用 `ROUND` 强制改变 PDF 金额精度。
- 审核时左侧国家列表独立滚动；同一国家的六个字段之间切换时列表保持不动，仅跨国家时让新国家进入可见区域。
- 目标季度不存在时，优先复制“季度模板”或“模板”，否则复制最近的历史季度。
- 新季度从模板复制时，会先清空全部国家的旧业务数据；只上传部分国家也不会残留其他国家的模板数值。
- 国家始终按站点、中文国家名和币种匹配，与 Excel 行顺序无关；缺少已上传国家时会自动在末尾追加一行。
- 巴西行可写作“巴西”或“巴西（联合报告）”。比利时、波兰等全零报告会写入数值 `0` 并照常嵌入完整截图，不再写“无”。
- 公司工作簿不是必选项：无工作簿时可下载蓝色表头、冻结标题行的解析汇总 Excel；每个国家的完整 PDF 报告截图会嵌入该国家数据行右侧。
- 直接修改 OOXML 包，保留原工作簿结构，并把每个国家的完整 PDF 报告截图嵌入 K 列。
- 写入前汇总是必经步骤；确认后一次生成并下载 Excel。

## 使用方法

1. 将本季度所有 PDF 放在同一文件夹，文件名使用 `2026Q2-HY-US-…pdf` 格式。
2. 打开在线页面，把 PDF 文件夹拖入第一个区域；如需写回公司格式，再把 `.xlsx` / `.xlsm` 工作簿拖入第二个区域。
3. 点击“解析并开始审核”，从第一个国家第一个字段开始核对。
4. 全部完成后检查最终汇总，并点击唯一的确认下载按钮。
5. 浏览器会下载一个新工作簿，原工作簿不会被修改。

## 本地直接使用

下载仓库中的 `local.html` 后直接双击即可运行。它是包含全部程序、样式和 PDF 解析组件的单文件版本，不要求安装 Node.js，也不需要启动本地服务器。浏览器仍只在本机内存中处理所选文件。

建议使用当前版本的 Chrome 或 Edge。工作簿与多页 PDF 会在内存中处理；非常大的文件应分批使用。

## 支持的字段

| 字段 | 来源/算法 | Excel 列 |
| --- | --- | --- |
| 收入 | Income subtotal Credits | E |
| 退款 | `ABS(Income subtotal Debits)` | F |
| 佣金返款 | Selling fee refunds Credits | G |
| 运费返款 | FBA transaction fee refunds Credits | H |
| 广告 | Cost of Advertising Debits | I |
| 佣金服务费 | `ABS(Expenses subtotal Debits) - 广告` | J（公式） |
| 完整报告截图 | PDF 全页纵向拼接 | K（图片） |

## 本地开发

要求 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

运行测试和生产构建：

```bash
npm test
npm run build
```

构建会同时生成：

- `dist/`：GitHub Pages 使用的静态站点。
- `local.html`：可直接双击运行的单文件离线版。

项目推送到 `main` 后，GitHub Actions 会测试、构建并部署 `dist` 到 GitHub Pages。

## 隐私与限制

- 本项目没有后端、账号系统或遥测代码，选择的业务文件只在当前浏览器标签页内处理。
- 浏览器安全模型不允许网页覆盖本机源文件，因此结果会作为新文件下载。
- 加密、损坏或非标准 OOXML 工作簿不受支持。
- 自动提取不能代替人工复核；页面强制逐字段审核，并在生成前显示最终汇总。
